# CN Market (沪深300 paper trading) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement task-by-task.

**Goal:** Add a parallel China A-share paper-trading universe (CSI300, CNY 10,000 / account, IDX3 = 沪深300 benchmark) running the exact same Alpha158 + GP-evolved strategies as the existing US system. Both markets coexist in the same SQLite DB; the dashboard gets a top-level `[US] [CN]` tab with US default.

**Architecture decisions (locked):**
- Data source: **akshare** (free, A-share quality > yfinance for CN)
- Universe: **CSI 300** constituents (`akshare.index_stock_cons_csindex(symbol="000300")`)
- Cron: every hour `0 * * * 1-5` (same as US), guarded by `is_market_hours_cn()` (09:30–11:30 + 13:00–15:00 CST)
- Account naming: **`CA01-CA10` / `CB01-CB10`**; benchmark `IDX3` (沪深300, ticker `000300.SH`)
- Initial cash: **¥10,000** per account
- Cost model: A-share fees (commission 0.025% double-sided ¥5 min, stamp tax 0.05% sells only, transfer fee 0.001% double-sided)
- Telegram report: **CN excluded** (user reads dashboard only)
- Schema: add `market` column (`US`/`CN`) to `account_meta`, `account_state`, `accounts`, `events`, `positions`, `positions_history`, `trades`, `adaptive_state`. Default `'US'` for backfill.
- Price storage: reuse `prices` table; CN tickers stored with `.SH`/`.SZ` suffix (akshare uses 6-digit codes — we add suffix on write)
- Inception: **CN starts trading from "now" (first cron after deploy)**. Historical price backfill goes as far back as akshare gives us (typically 20+ years for index, 5-10y individual stocks).

**Tech stack:** Python 3.11, akshare, existing pandas/SQLite/yfinance stack, FastAPI dashboard.

### Task 1.1: Add `market` column to all account-scoped tables
**Files:** Create `scripts/migrate_add_market.py`
```python
"""Add market column ('US'|'CN') to account-scoped tables. Idempotent."""
import sqlite3, sys
from pathlib import Path
DB = Path.home() / "quant-trading/data/trading.db"

TABLES = ["account_meta", "account_state", "accounts", "events",
          "positions", "positions_history", "trades", "adaptive_state"]

def has_col(con, table, col):
    return any(r[1] == col for r in con.execute(f"PRAGMA table_info({table})"))

def main():
    con = sqlite3.connect(DB); con.execute("PRAGMA foreign_keys=ON")
    for t in TABLES:
        if not has_col(con, t, "market"):
            con.execute(f"ALTER TABLE {t} ADD COLUMN market TEXT NOT NULL DEFAULT 'US'")
            print(f"+ {t}.market")
    # index for fast filter
    con.execute("CREATE INDEX IF NOT EXISTS idx_trades_market_ts ON trades(market, timestamp)")
    con.execute("CREATE INDEX IF NOT EXISTS idx_events_market_ts ON events(market, ts)")
    con.commit()
    print("done")

if __name__ == "__main__":
    main()
```

### Task 2.2: Add CN cost model
**Files:** Modify `config/settings.py` (add `CNFeeStructure`)
```python
@dataclass(frozen=True)
class CNFeeStructure:
    """A-share fees (T+1, lot=100 enforced upstream)."""
    commission_rate: float = 0.00025      # 0.025% double-sided
    commission_min: float = 5.0           # ¥5 minimum per order
    stamp_tax_rate: float = 0.0005        # 0.05% sells only
    transfer_fee_rate: float = 0.00001    # 0.001% double-sided (Shanghai+SZ unified 2022+)
    slippage_pct: float = 0.0005

    def calc_fees(self, shares: float, price: float, is_sell: bool = False) -> dict:
        notional = abs(shares) * price
        commission = max(notional * self.commission_rate, self.commission_min)
        transfer = notional * self.transfer_fee_rate
        stamp = notional * self.stamp_tax_rate if is_sell else 0.0
        slippage = notional * self.slippage_pct
        total = commission + transfer + stamp + slippage
        return {"commission": round(commission, 4), "transfer": round(transfer, 4),
                "stamp": round(stamp, 4), "slippage": round(slippage, 4),
                "total": round(total, 4)}

CN_FEES = CNFeeStructure()
FEES_BY_MARKET = {"US": FEES, "CN": CN_FEES}
```

```python
def to_yf_suffix(code: str) -> str:
    code = str(code).zfill(6)
    if code.startswith(("60","68","51","58")): return f"{code}.SH"
    if code.startswith(("00","30","15","16")): return f"{code}.SZ"
    return code

def main():
    df = ak.index_stock_cons_csindex(symbol="000300")
    col = "成分券代码" if "成分券代码" in df.columns else df.columns[4]
    tickers = sorted({to_yf_suffix(c) for c in df[col]})
    out = Path.home() / "quant-trading/data/cn_universe.json"
    out.write_text(json.dumps({"updated": __import__("datetime").datetime.utcnow().isoformat(),
                                "count": len(tickers), "tickers": tickers}, indent=2))
    print(f"wrote {len(tickers)} tickers → {out}")

if __name__ == "__main__":
    main()
```

### Task 3.1: Add CN fetcher
**Files:** Create `data/cn_fetcher.py`
```python
"""akshare-backed CN price fetcher. Same interface as DataFetcher.get_historical."""
import logging, pandas as pd, akshare as ak
from datetime import datetime, timedelta, timezone
from data.store import DataStore

log = logging.getLogger("quant.cn")

def _split_code(ticker: str) -> tuple[str, str]:
    """'600519.SH' → ('600519', 'sh'). '000300.SH' (index) → ('000300','sh')."""
    code, suffix = ticker.split(".")
    return code, suffix.lower()

def _hist_one(ticker: str, start: str, end: str, interval: str) -> pd.DataFrame:
    code, ex = _split_code(ticker)
    is_index = code in ("000300", "000001", "399001", "399006")
    try:
        if is_index:
            df = ak.stock_zh_index_daily(symbol=f"{ex}{code}")
            df = df.rename(columns={"date":"datetime"})
        elif interval == "1d":
            df = ak.stock_zh_a_hist(symbol=code, period="daily",
                                    start_date=start.replace("-",""),
                                    end_date=end.replace("-",""), adjust="qfq")
            df = df.rename(columns={"日期":"datetime","开盘":"open","收盘":"close",
                                    "最高":"high","最低":"low","成交量":"volume"})
        elif interval in ("1h","60m"):
            df = ak.stock_zh_a_hist_min_em(symbol=code, period="60",
                                           start_date=f"{start} 09:00:00",
                                           end_date=f"{end} 16:00:00", adjust="qfq")
            df = df.rename(columns={"时间":"datetime","开盘":"open","收盘":"close",
                                    "最高":"high","最低":"low","成交量":"volume"})
        else:
            return pd.DataFrame()
        if df.empty: return df
        df["datetime"] = pd.to_datetime(df["datetime"]).dt.strftime("%Y-%m-%d %H:%M:%S")
        df["ticker"] = ticker
        return df[["datetime","ticker","open","high","low","close","volume"]].dropna()
    except Exception as e:
        log.warning("akshare fetch %s failed: %s", ticker, e)
        return pd.DataFrame()

class CNDataFetcher:
    def __init__(self):
        self.store = DataStore()

    def get_historical(self, tickers, days=30, interval="1d", use_cache=True):
        end = datetime.now(timezone.utc).replace(tzinfo=None)
        start = end - timedelta(days=days)
        s, e = start.strftime("%Y-%m-%d"), end.strftime("%Y-%m-%d")
        if use_cache:
            cached = self.store.load_prices(tickers, s, e, interval=interval)
            cov = self.store.get_price_coverage(tickers, interval=interval)
            expected = max(1, int(days * 0.6)) if interval == "1d" else max(1, int(days*0.6*4))
            missing = [t for t in tickers if not cov.get(t) or cov[t][2] < expected]
            if not missing:
                return cached
            log.info("CN cache miss: %d/%d tickers, downloading...", len(missing), len(tickers))
            frames = []
            from concurrent.futures import ThreadPoolExecutor
            with ThreadPoolExecutor(max_workers=8) as ex:
                for df in ex.map(lambda t: _hist_one(t, s, e, interval), missing):
                    if not df.empty: frames.append(df)
            if frames:
                self.store.save_prices_bulk(pd.concat(frames, ignore_index=True), interval=interval)
            return self.store.load_prices(tickers, s, e, interval=interval)
        # force fetch
        frames = [_hist_one(t, s, e, interval) for t in tickers]
        frames = [f for f in frames if not f.empty]
        if frames:
            self.store.save_prices_bulk(pd.concat(frames, ignore_index=True), interval=interval)
        return pd.concat(frames, ignore_index=True) if frames else pd.DataFrame()
```

```python
from zoneinfo import ZoneInfo
_CST = ZoneInfo("Asia/Shanghai")

def is_market_hours_cn() -> bool:
    now = datetime.now(_CST)
    if now.weekday() >= 5: return False
    m = now.hour*60 + now.minute
    return (9*60+30 <= m < 11*60+30) or (13*60 <= m < 15*60)

def is_market_hours_for(market: str) -> bool:
    return is_market_hours() if market == "US" else is_market_hours_cn()
```

## Pitfalls / Notes

- **akshare rate limit**: ~1 req/sec for some endpoints. CSI300 historical with 8 threads is ~40s; intraday will need throttling.
- **A-share lot size = 100** for buys (sells can be any). Add validation in `TradingEngine` or accept fractional in paper mode (recommend the latter — paper sim, simpler).
- **T+1 settlement**: cannot sell shares bought same day. Track `bought_date` on positions or just block via timestamp check.
- **Suspended stocks**: akshare returns gaps; `skip_zero_volume=True` already handles this.
- **CST cron**: server cron runs UTC. `0 * * * 1-5` already covers all CST hours; the per-market guard handles open/close.
- **Index ticker convention**: store `000300.SH` in DB; akshare wants `sh000300` — CNDataFetcher translates.
- **DataStore.market filter must default 'US'**: any code path that forgets to pass `market` keeps working on US (no silent CN data leakage into US views).
- **Currency rendering**: never sum USD+CNY; tabs are fully isolated.
- **Position max_position_pct, max_positions**: same as US — no per-market override yet (YAGNI).
